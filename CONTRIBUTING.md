# Contributing

Thanks for your interest in making this tool useful to freelancers.

1. Check existing issues and open a discussion before large changes.
2. Fork the repository and create a feature branch.
3. Run `npm install` and `npm run build` before submitting.
4. Submit a pull request describing the change, manual testing and any limitations.
5. Do not commit API keys, private client data, passwords or proprietary assets.

Please be respectful and constructive in issue and pull request discussions.
